# Module Utils

Ce module contient les utilitaires et fonctions d'aide :

## Composants

### Utilitaires de cartes
- `card_utils.h/c` - Utilitaires de manipulation de cartes
- `deck_utils.h/c` - Utilitaires de jeux de cartes
- `universal_deck.h/c` - Interface universelle pour tous les jeux

### Combinaisons et permutations
- `combinations.h/c` - Calculs de combinaisons
- `permutations.h/c` - Calculs de permutations

### Optimisations micro
- `micro_optimizations.h/c` - Micro-optimisations
- `bit_operations.h/c` - Opérations sur les bits

### Wrappers et interfaces
- `poker_wrapper.h/c` - Wrapper principal
- `export_definitions.h` - Définitions d'export

### Génération de tables
- `table_generator.h/c` - Génération de tables de lookup
- `mktable_utils.h/c` - Utilitaires de création de tables
